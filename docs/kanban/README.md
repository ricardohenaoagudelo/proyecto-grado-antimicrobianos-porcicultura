# Gestión del proyecto mediante Kanban

Para organizar y controlar el desarrollo del prototipo se utilizó la metodología ágil **Kanban**, permitiendo visualizar el avance de las actividades y mantener trazabilidad sobre las tareas realizadas durante el proyecto.

El tablero final se organizó en tres estados:

- **Pendiente futuro**
- **En proceso**
- **Terminado**

## Interpretación

Al cierre de la Fase 4, la mayoría de las actividades relacionadas con el desarrollo y validación del prototipo fueron trasladadas a la columna **Terminado**.

Las actividades que permanecen en **Pendiente futuro** corresponden a mejoras y etapas posteriores que exceden el alcance definido para esta fase académica.

La revisión final del documento maestro permanece temporalmente en la columna **En proceso** hasta completar la actualización de contenido
