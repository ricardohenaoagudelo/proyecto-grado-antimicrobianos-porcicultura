# Nivel de madurez tecnológica – TRL 5

El prototipo desarrollado presenta características compatibles con un **Technology Readiness Level 5 (TRL 5)** dentro del alcance académico del proyecto.

## Justificación

La solución integra sus principales componentes funcionales:

- Interfaz de captura de datos en Google AppSheet.
- Reglas de validación de entrada.
- Expresiones y lógica de cálculo.
- Almacenamiento estructurado en Google Sheets.
- Registro histórico de tratamientos.
- Consulta detallada de registros.
- Visualizaciones gráficas.
- Tablero de control.
- Pruebas funcionales.
- Pruebas de validación.
- Evaluación preliminar de usabilidad.

El funcionamiento del sistema fue evaluado mediante escenarios controlados representativos del proceso de cálculo de tratamientos antimicrobianos administrados mediante agua de bebida en producción porcina.

## Evidencias de validación

Para verificar el funcionamiento del prototipo se utilizaron:

- Seis escenarios funcionales de cálculo.
- Comparación entre resultados manuales y resultados generados por la aplicación.
- Doce pruebas de validación de datos de entrada.
- Revisión del almacenamiento de los registros.
- Consulta del historial y detalle de tratamientos.
- Evaluación preliminar de usabilidad con cinco participantes.

Los resultados obtenidos mostraron concordancia entre los cálculos manuales de referencia y los generados por el prototipo.

La prueba preliminar de usabilidad obtuvo una valoración promedio de **4,6 sobre 5**.

## Entorno de validación

La validación se realizó principalmente en un entorno controlado utilizando escenarios representativos del proceso real.

No se realizó todavía una validación extensa en condiciones productivas reales de granja.

Por esta razón, el nivel de madurez debe interpretarse dentro del alcance de un prototipo académico y no como una solución comercial completamente implementada.

## Limitaciones actuales

Para avanzar hacia niveles superiores de madurez tecnológica se requiere:

- Validación en granjas reales.
- Evaluación con un mayor número de usuarios.
- Seguimiento del desempeño en condiciones productivas.
- Integración futura con mediciones reales de consumo de agua.
- Evaluación de escalabilidad.
- Migración hacia fuentes de datos con mayor capacidad cuando el volumen de información lo requiera.

## Conclusión

La integración de los componentes principales y su evaluación mediante pruebas funcionales, validaciones de entrada y escenarios representativos permiten considerar que el prototipo presenta un nivel de madurez tecnológica compatible con **TRL 5**.

El sistema constituye una base funcional para continuar con etapas posteriores de validación, mejora y escalabilidad.
