# Capturas y evidencias visuales del prototipo

Esta carpeta contiene evidencias visuales de las principales funcionalidades implementadas en el prototipo desarrollado en Google AppSheet.

Las capturas permiten verificar la existencia y funcionamiento de las interfaces utilizadas durante la Fase 4 del proyecto.

## Evidencias recomendadas

Se recomienda almacenar las siguientes imágenes:

| Archivo | Evidencia |
|---|---|
| `01-pantalla-inicio.png` | Pantalla principal o de bienvenida |
| `02-formulario-tratamiento.png` | Formulario para registrar un nuevo tratamiento |
| `03-validacion-datos.png` | Ejemplo de mensaje o restricción ante un valor inválido |
| `04-calculo-exitoso.png` | Resultado de un cálculo válido |
| `05-historial-tratamientos.png` | Vista del historial de tratamientos registrados |
| `06-detalle-tratamiento.png` | Vista detallada de un tratamiento almacenado |
| `07-dashboard.png` | Tablero de control con visualizaciones |
| `08-graficos.png` | Evidencia de los gráficos implementados |

## Recomendaciones

Las capturas utilizadas como evidencia deben:

- Mostrar claramente la funcionalidad evaluada.
- Evitar datos personales o información sensible.
- Utilizar datos ficticios o anonimizados cuando sea necesario.
- Mantener una resolución que permita leer los campos principales.
- Utilizar nombres descriptivos y numerados para facilitar su consulta.

## Relación con la validación

Las evidencias visuales complementan:

- Las pruebas funcionales.
- Las pruebas de validación de entrada.
- La documentación del nivel TRL 5.
- El manual de usuario.
- La demostración presentada en el video final.

## Nota

Estas imágenes tienen fines académicos y documentales y corresponden al estado del prototipo durante la Fase 4.
