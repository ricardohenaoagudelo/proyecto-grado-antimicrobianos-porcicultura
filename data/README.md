# Datos de prueba

Esta carpeta contiene datos utilizados exclusivamente para fines académicos, demostrativos y de validación del prototipo.

## Tipo de información

Los archivos almacenados en esta carpeta deben corresponder únicamente a:

- Datos ficticios.
- Datos simulados.
- Registros anonimizados.
- Escenarios utilizados en pruebas funcionales.
- Información creada específicamente para validar cálculos del prototipo.

## Restricciones

No se deben almacenar:

- Datos personales de usuarios.
- Información confidencial de granjas.
- Registros clínicos reales identificables.
- Información comercial sensible.
- Correos electrónicos, nombres completos u otros datos que permitan identificar personas o empresas.

## Uso de los datos

Los datos pueden utilizarse para:

- Ejecutar pruebas funcionales.
- Validar fórmulas.
- Verificar reglas de entrada.
- Generar capturas de pantalla.
- Demostrar el funcionamiento del prototipo.
- Reproducir escenarios utilizados durante la Fase 4.


## Nota

La información incluida en esta carpeta no corresponde a tratamientos reales y se utiliza únicamente como evidencia académica del funcionamiento del prototipo.
